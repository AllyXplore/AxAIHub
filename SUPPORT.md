## Before you report / 提交前请先

1. Update to the latest release. 升级到最新发布版本。
2. Search existing issues, including closed ones. 搜索已有 issue，包括已关闭的。
3. Read [docs/FAQ.md](docs/FAQ.md). 阅读常见问题。

## What makes a report useful / 什么样的反馈最有效

- app version and device model / 应用版本与设备型号
- Android version and system skin / 系统版本与系统定制版本
- exact steps to reproduce / 明确的复现步骤
- what you expected, and what happened instead / 期望结果与实际结果
- a screenshot or screen recording / 截图或录屏
- whether the problem also occurs with plugins disabled / 停用插件后是否仍然出现

Please remove personal information from screenshots and logs before posting.
发布截图与日志前请先移除个人信息。

## Support policy / 支持范围说明

AxAIHub is provided as is by a very small team. We read reports and fix what we can, but:
AxAIHub 由极小的团队按现状提供。我们会阅读反馈并尽力修复，但请注意：

- there is no guaranteed response time and no staffed customer service;
  不承诺响应时限，也没有专职客服；
- not every request will be implemented — the project deliberately stays focused;
  并非每个需求都会实现，项目会有意保持克制；
- third-party plugins are supported by their own authors, not by us;
  第三方插件由其作者负责支持，不在我们的支持范围内；
- problems caused by modified or unofficially signed builds cannot be investigated.
  经修改或非官方签名版本导致的问题无法排查。

Thanks for using AxAIHub, and for taking the time to write things up carefully.
感谢使用 AxAIHub，也感谢你认真写下反馈。
