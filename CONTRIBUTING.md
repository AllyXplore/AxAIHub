# Contributing / 参与方式

Thank you for the interest. A short note on how this repository works, so nobody wastes effort.
感谢关注。先说明本仓库的定位，避免你白费功夫。

## This is a distribution repository / 这是分发仓库

AxAIHub is proprietary software. This repository holds release installers, documentation and the issue
tracker — **not** the application source code. Pull requests containing application code cannot be
accepted, and code contributions are not solicited here.

AxAIHub 为闭源软件。本仓库存放发布安装包、文档和问题反馈入口，**不包含**应用源代码。
因此无法接受包含应用代码的合并请求，也不在此征集代码贡献。

## What is genuinely welcome / 真正欢迎的参与

| Contribution / 参与形式 | How / 方式 |
| --- | --- |
| Bug reports / 缺陷报告 | Open an issue with the bug template / 用缺陷模板提交 issue |
| Feature ideas / 功能建议 | Open an issue with the feature template / 用建议模板提交 issue |
| Documentation fixes / 文档修正 | Pull request against files in this repository / 针对本仓库文件提交合并请求 |
| Translations of this documentation / 文档翻译 | Pull request, one language per file / 提交合并请求，每种语言单独文件 |
| Compatibility reports / 兼容性反馈 | Tell us the device, system version and what broke / 提供设备、系统版本与故障现象 |
| Plugins / 插件 | Build and publish your own; see the plugin documentation in the app / 自行开发并发布，参见应用内插件文档 |

For documentation pull requests: keep changes focused, keep both language versions in sync when the
change affects meaning, and avoid reformatting whole files.
文档类合并请求：请保持改动聚焦；若改动涉及含义，请同步更新中英两个版本；不要整篇重排格式。

## Writing conventions / 写作约定

- No emoji in documentation. 文档中不使用表情符号。
- Plain wording over marketing wording. 用平实措辞，避免营销腔。
- English files are the international entry point; Chinese files carry the same information, not a
  literal translation. 英文文件面向国际读者；中文文件传达同样的信息，不必逐字对译。
- Never include personal data, credentials, private keys or device identifiers in an issue or a
  pull request. 不要在 issue 或合并请求中包含个人数据、凭据、私钥或设备标识。

## Filing a good issue / 如何写好一条 issue

See [SUPPORT.md](SUPPORT.md) for the checklist. Reports that include the app version, device, system
version and reproduction steps get resolved far faster than reports that do not.
清单见 [SUPPORT.md](SUPPORT.md)。附上应用版本、设备、系统版本与复现步骤的反馈，处理速度会快得多。

## Conduct / 行为准则

Participation in this repository is subject to [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
参与本仓库需遵守 [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)。

## Licence of your contribution / 贡献的许可

By submitting a documentation or translation pull request, you agree that your contribution may be
published in this repository and reused in AxAIHub documentation, with attribution in the commit history.
提交文档或翻译类合并请求，即表示你同意该内容可在本仓库发布，并可用于 AxAIHub 的文档，
署名以提交记录为准。
